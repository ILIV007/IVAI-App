# Code of Conduct

## Our commitment

IVAI welcomes constructive participation from people with different backgrounds, languages, accessibility needs, and levels of technical experience. We commit to a collaboration space that is respectful, professional, and focused on improving a Local-first, Backendless, BYOK Android Agent Harness.

## Expected behavior

Contributors, reviewers, issue authors, and maintainers are expected to communicate in good faith; focus criticism on ideas, code, evidence, and documented safety boundaries; welcome correction; use inclusive language; respect privacy; and help keep discussions reproducible and technically specific.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, intimidation, deliberate disruption, publication of private information, or pressure to disclose credentials, prompts, workspace files, device identifiers, or other sensitive material is not acceptable. Do not use repository discussions to request unsafe feature changes that bypass IVAI's explicit approval, provider-selection, workspace-isolation, or Local-first/BYOK boundaries.

## Enforcement

If you experience or observe unacceptable behavior, contact the repository owner privately through the GitHub profile associated with this repository. Use a concise factual description and avoid including sensitive personal or security information. The owner may clarify expectations, request a correction, remove content, restrict participation, or take another proportionate action.

## Scope

This Code of Conduct applies to repository discussions, issues, pull requests, reviews, releases, and other spaces where a participant represents the IVAI project.
